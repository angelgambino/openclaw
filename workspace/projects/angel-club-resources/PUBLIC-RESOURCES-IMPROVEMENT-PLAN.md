## 2. Rules & Constraints

### Non-Negotiable (Angel's Rules)
| Rule | Rationale |
|------|-----------|
| ❌ No emails | Private — members-only benefit |
| ❌ Don't rival the Master DB on depth | 12,000+ investors is the premium product |
| ✅ Include ALL investor types | VCs, Angel Groups, Syndicates, Individual Angels, Family Offices, CVCs |
| ✅ Add pitch submission URLs | High value, publicly available |
| ✅ Add LinkedIn profiles for individuals | Publicly available, high value |
| ✅ Add all resource categories | Competitions, demo days, grants, tools, podcasts |
| ✅ Optimize for SEO + AI discovery | Drive traffic to Angel Club |
| ✅ ALWAYS include Location | City + State/Country on every list. No blank location fields. |

### Value Gap Strategy
The public list should be **wide but shallow** on investors. The Master DB is **deep and actionable**.

| Dimension | Public List | Master DB (Members) |
|-----------|------------|-------------------|
| Investors | ~300–500 curated (all types) | 12,000+ with full contacts |
| Contact Info | Website + LinkedIn + pitch URL only | Emails, phone, intro paths |
| Check Size | General range | Specific amounts |
| Portfolio | Not included | Full portfolio data |
| Warm Intros | Not available | Available via network |
| Other Resources | Comprehensive (15 tabs) | — |
